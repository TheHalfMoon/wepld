# Specification — WePLD Fresh Reconstitution Foundation

## Objective

Create a minimal, clean, documentation-only canonical foundation that lets any future chat/agent restore WePLD accurately and build it under the ratified method without inheriting obsolete repository architecture.

## Required outcomes

- root `AGENTS.md` provides one bootstrap entry;
- canonical current state and invariants are explicit;
- V2.2 plan is preserved;
- founder ratification summary is preserved;
- mandatory Spec Kit/Ponytail/reviewer/build-learning protocol is explicit;
- complete 402-entry source registry is present;
- source artifact pins and acquisition evidence are present;
- fresh dependency register starts at zero admitted implementation dependencies;
- old main, PR #1 and PR #11 are treated as historical quarries with a salvage ledger;
- no code is introduced;
- publication targets only the founder-selected owner/admin repository `TheHalfMoon/wepld`; no implementation code is introduced.

## Non-goals

- S1 implementation;
- dependency installation;
- source import;
- visibility/ruleset mutation;
- closing PRs;
- final UI design;
- Windows containment implementation;
- source admission.
