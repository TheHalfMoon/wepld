# Specification — Fresh Reconstitution Foundation

Create the minimum canonical repository-memory foundation that lets any future worker restore WePLD accurately and build under the ratified architecture/method without inheriting obsolete code.

Required: AGENTS bootstrap, current state, invariants, V2.2 index, ratification, build method, 402-source registry index, mining priorities, build-learning protocol, historical salvage index, zero dependency register, and empty `src/`.

Non-goals: S1 code, dependency installation, source import, UI design, Windows containment implementation, or source admission.
