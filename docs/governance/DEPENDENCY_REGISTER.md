# Dependency Register

**Fresh-reconstitution state:** zero implementation dependencies admitted.

The existing public `main` branch has documentation CI dependencies, and historical PR #1 has a Rust dependency set. Those are historical evidence only for the fresh tree.

Every future dependency requires:
- capability need;
- source registry/acquisition record;
- exact version/hash;
- license/NOTICE;
- transitive dependency and SBOM evidence;
- security/advisory review;
- platform/maintenance state;
- admission decision;
- update and exit strategy.
